# 지도 렌더링 방식 (SPEC 4.4)

유휴토지 지도(`frontend/components/land/ParcelMap.tsx`)가 왜 타일 지도 라이브러리
대신 **좌표 SVG** 를 쓰는지에 대한 기록이다.

## 제약

1. 프론트엔드는 정적 내보내기다 (`next.config.ts` 의 `output: 'export'`).
   서버 컴포넌트에서 런타임 데이터를 가져올 수 없고, 브라우저에서만 도는 코드여야 한다.
2. 검증은 **외부 네트워크 없이** 돈다. `docker-compose.test.yml` 은 앱 컨테이너와
   Playwright 컨테이너만 띄우며, 데모도 같은 이미지를 오프라인에서 돌릴 수 있어야 한다
   (docs/ARCHITECTURE.md 의 "컨테이너는 하나다").
3. 차트 의존성은 recharts 하나로 고정돼 있다 (`frontend/components/charts/index.ts`).
   지도 때문에 두 번째 렌더링 스택을 들이는 것은 값이 비싸다.

## 검토한 선택지

| 선택지 | 정적 내보내기 | 오프라인 | 판단 |
|---|---|---|---|
| Leaflet / react-leaflet + OSM 타일 | 가능 (`ssr: false` 동적 임포트 필요) | ✗ 타일 요청이 매번 나간다 | 오프라인에서 회색 판만 남는다 |
| MapLibre GL + 벡터 타일 | 가능 | ✗ 스타일·타일 URL 과 대개 키가 필요 | 위와 같음 |
| 타일을 리포에 동봉 | 가능 | ○ | 한 지역만 담아도 수십 MB — 이미지 크기가 감당 안 된다 |
| **좌표 SVG (채택)** | 가능 | ○ | 의존성 0, 항상 같은 그림 |

## 채택한 방식

`GET /api/parcels/geojson` 의 좌표를 **등장방형(equirectangular) 투영**으로 SVG 에
찍는다. 배경은 타일 이미지가 아니라 좌표계 자체다:

- 위경도 격자(그라티큘)와 눈금 라벨 — 실제 지도와 겹쳐 볼 수 있다
- haversine 으로 계산한 축척 막대
- `GET /api/regions` 의 시군구 중심점 — 어느 지역인지 가늠할 맥락

필지 마커 색은 백엔드가 `condition` 에서 정해 내려준 값
(`상태 최상(녹) / 상태 양호(황) / 개선 필요(적)`)을 디자인 시스템의 시맨틱 토큰
(`--color-good` / `--color-warn` / `--color-bad`)으로 옮겨 쓴다. 응답의 `color_hex`
를 그대로 쓰지 않는 이유는 다크 모드에서 대비가 무너지기 때문이다.

경도는 중심 위도의 `cos` 로 줄여 실제 거리 비율을 맞춘다. 시군구 몇 개 범위에서는
왜곡이 눈에 띄지 않는다. 전국 단위로 넓어지면 이 가정이 깨지므로, 그때는 투영을
`ParcelMap.tsx` 의 `project()` 한 곳만 바꾸면 된다.

## 타일 배경을 붙이려면

`project()` 가 만든 화면 좌표는 그대로 두고, 격자 아래에 `<image>` 한 장을 깔면
된다. 다만 그 순간 **오프라인 보장이 깨진다.** 타일 제공자를 쓰기로 결정한다면
`NEXT_PUBLIC_MAP_TILE_URL` 같은 환경변수로 감싸서, 값이 없을 때는 지금의 좌표
격자로 되돌아가도록 두는 것이 안전하다.
